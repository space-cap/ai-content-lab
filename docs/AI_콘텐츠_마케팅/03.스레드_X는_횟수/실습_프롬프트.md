# 딥리서치 기반 로컬 AI 스레드 & X 글 생성기 제작

LM Studio 로컬 AI와 연동되는 **단일 HTML 파일(standalone.html)** 웹앱을 만들어줘.
빌드 도구 없이 브라우저에서 바로 열리는 완전한 파일 하나로 작성해줘.

## 기술 스택 (CDN만 사용, 빌드 없음)
- React 18 UMD + Babel Standalone (`<script type="text/babel">`)
- Tailwind CSS (cdn.tailwindcss.com)
- Font Awesome 6 아이콘, canvas-confetti
- 폰트: Plus Jakarta Sans, Noto Sans KR, JetBrains Mono (Google Fonts)

## 디자인
- 다크 테마: 배경 #080a10, 보라(#a855f7)→핑크(#ec4899)→시안(#06b6d4) 그라데이션 포인트
- 글래스모피즘 카드 (반투명 배경 + backdrop-blur + 얇은 흰색 테두리)
- 배경에 은은한 radial-gradient 광원 2개 (좌상단 보라, 우하단 시안)
- 레이아웃: 좌측 4칸 입력 폼 / 우측 8칸 결과 영역 (lg:grid-cols-12, 모바일에선 1열)
- 언어: 전체 UI 한국어

## LM Studio 연동 (핵심)
`http://127.0.0.1:1234` 의 OpenAI 호환 API를 fetch로 직접 호출 (CORS 허용됨):

1. **헬스체크**: `GET /v1/models` (4초 타임아웃, AbortController)
   - 응답 모델 목록에서 `embed`가 이름에 포함된 모델은 제외
   - 헤더에 연결 상태 배지(연결됨=초록/오프라인=빨강) + 모델 선택 드롭다운 표시
   - 15초마다 자동 재확인 (생성 중에는 스킵)
2. **생성**: `POST /v1/chat/completions` with `stream: true`
   - SSE 스트리밍 파싱: `data: ` 라인을 줄 단위로 버퍼링해서 JSON 파싱, `[DONE]` 처리
   - **중요 — 추론(reasoning) 모델 대응**: LM Studio의 일부 모델(gemma 등)은
     `delta.content` 전에 `delta.reasoning_content`를 먼저 스트리밍함.
     reasoning_content는 본문에 넣지 말고 별도 콜백으로 받아서
     "🧠 모델이 깊게 생각하는 중... (n자 추론)" 인디케이터로 표시할 것.
     추론 토큰이 max_tokens를 소모하므로 max_tokens는 3072~4096으로 넉넉하게.
   - 본문에 `<think>...</think>` 태그가 섞여 나오는 모델 대비: 파싱 전에 정규식으로 제거
     (닫히지 않은 `<think>`도 제거)
   - AbortController로 생성 중단(⏹) 버튼 지원
3. 설정 패널: baseUrl 수정 + 연결 테스트 버튼, 실패 시
   "LM Studio 앱에서 Developer 탭 → Start Server 확인" 안내 문구

## 딥리서치 3단계 파이프라인 (이 앱의 핵심 기능)
"딥리서치 모드"에서는 생성 버튼 1번에 LLM을 **3번 순차 호출**:

### 1단계: 딥리서치 (temperature 0.4, max_tokens 4096)
- system: "소셜미디어 콘텐츠 전략 리서처. 글을 쓰지 말고 리서치만 할 것"
- 출력 형식을 마크다운 헤딩으로 강제:
  `## 타깃 독자 분석` / `## 핵심 페인포인트`(3가지) / `## 핵심 인사이트`(구체적 숫자·사례 포함 5가지) / `## 흔한 오해` / `## 후킹 앵글 후보`(첫 문장 후보 3가지)

### 2단계: 전략 설계 (temperature 0.5, max_tokens 3072)
- system: "스레드 구성 전문가. 글 말고 설계도만 작성"
- 1단계 리서치 전문을 user 메시지에 포함
- 출력: `## 선택한 후킹 앵글`(1개+이유) / `## 스레드 구조`(N번 포스트: 역할 — 내용 요약, 마지막은 반드시 요약+CTA) / `## 관통하는 한 문장`

### 3단계: 최종 작성 (temperature 0.75, max_tokens 4096)
- system: "팔로워 수십만 크리에이터" 페르소나 + 작성 원칙:
  - 포스트당 글자 수 제한 엄수 (Threads 500자 / X 280자)
  - 첫 문장으로 스크롤 멈추게 할 것
  - 1~2문장 단위로 끊고 빈 줄로 구분 (모바일 가독성)
  - "~에 대해 알아보겠습니다" 같은 AI 티 나는 표현 금지
  - 구체적 숫자·사례 우선, 해시태그는 마지막 포스트에만 최대 2개
- **출력 형식 강제**: 각 포스트를 `###POST###` 구분선으로 분리, 포스트 번호("1/5") 붙이지 말고
  본문만, 인사말 없이 바로 첫 구분선부터 시작
- user 메시지에 리서치 보고서 + 설계도 전문 포함

빠른 생성 모드(⚡)는 1·2단계를 건너뛰고 3단계 스타일 프롬프트 1회 호출.

## 결과 파싱
1. `###POST###` 기준 split (정규식 `/#{2,}\s*POST\s*#{2,}/i`로 유연하게)
2. 폴백: `1/`, `1.`, `[1/5]` 같은 번호 패턴으로 분리
3. 최종 폴백: 전체를 포스트 1개로
각 포스트는 `{ id, content, charCount }`로 관리.

## 입력 폼
- 생성 모드 토글: 🧠 딥리서치(3단계) / ⚡ 빠른 생성(1단계)
- 플랫폼: 🧵 Threads(500자) / 𝕏 Twitter(280자)
- 글 형태: 단일 포스트(1개) / 숏 스레드(4~5개) / 롱 스레드(7~9개)
- 주제(필수), 타깃 독자(선택), 강조 메시지/추가 메모(선택)
- 어투 select: 바이럴 후킹 / 친근·유쾌 / 전문가 / 직설 — 각 어투는 프롬프트에서
  구체적 서술로 변환 (예: "바이럴 후킹형 — 강렬한 호기심 유발, 짧고 임팩트 있는 문장, 반전과 넘버링 활용")
- 생성 중: 버튼이 현재 단계명 표시("리서치 중.../전략 설계 중.../글 작성 중...") + 중단 버튼

## 우측 결과 영역
1. **파이프라인 진행 표시**: 3개 스텝 카드(딥리서치→전략 설계→최종 작성),
   상태별 스타일 (진행 중=보라 글로우+pulse, 완료=초록 체크, 대기=흐리게)
2. **리서치 보고서 & 설계도 패널**: 접기/펼치기, 스트리밍 중 실시간 표시 + 타이핑 커서(▊),
   자동 스크롤. 생성 완료되면 자동으로 접힘
3. **스레드 카드 미리보기**: SNS 포스트 모양 카드 (프로필 아바타, 닉네임, n/N 표시),
   카드 사이 세로 연결선(스레드 느낌), 실시간 스트리밍 렌더링
   - 글자 수 배지: `현재/제한자`, 제한 초과 시 주황색 경고
   - 카드별 복사 버튼 + 전체 복사 버튼 (복사 성공 시 "복사됨!" 피드백 + confetti)

## 기타
- 생성 기록: 최근 20개, 클릭하면 포스트+리서치+설계도 복원 (메모리 상태로만, localStorage 불필요)
- 에러 배너: 생성 실패/중단 시 상단에 닫기 가능한 빨간 배너
- 푸터: "100% 로컬 실행 · 데이터는 외부로 전송되지 않습니다"
