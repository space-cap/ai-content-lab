# 🧪 AI Content Lab (인공지능 콘텐츠 실험실)

다양한 생성형 AI 기반 서비스 아이디어의 기획, PRD, 그리고 동작하는 프론트엔드 프로토타입을 빠르게 실험하고 검증하는 모노레포 실험실입니다.

---

```text

├── 📚 docs/                           # 기획, PRD, 와이어프레임 설계 문서

│   │   ├── 01.할담소_서비스_기획서.md
│   │   ├── 02.할담소_PRD_제품요구사항정의서.md
│   │   └── 03.할담소_화면설계서_및_와이어프레임.md

└── 🧪 prototypes/                     # 아이디어별 독립 동작 프로토타입
    └── haldamso/                      # 👵 1호 프로토타입: 할담소 웹 앱
        ├── src/
        └── package.json
```

## 👵 [프로토타입 1호] 할담소 (랜선 밥 사주는 어른)

* **서비스 설명**: 청년은 100% 무료로 인생 고민을 털어놓고 국밥 기프티콘(10,000원)을 얻고, 어르신은 비용 부담 0원으로 인생의 지혜를 전하는 세대 상생 역발상 플랫폼. (기업 ESG 스폰서 매칭)
* **주요 기능**:
  - **어르신 전용 모드**: 24pt~32pt 초대형 폰트, 브라우저 음성(TTS) 청년 고민 낭독, 지름 120px 원터치 마이크 육성 녹음기, 스폰서 매칭 팝업
  - **청년 모드**: 4대 멘토 성향 선택, 익명 고민 등록, 알림톡 연동 폼
  - **명예의 전당**: 실시간 뚝배기 완식 인증샷 & 눈물의 손편지 감동 전광판

### 💻 실행 방법

```bash
cd prototypes/haldamso
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 시 바로 모바일 반응형 프로토타입을 체험하실 수 있습니다.
